# 情绪五分类标注规范

## 目标

把项目从二分类升级为五分类，覆盖大学生情绪日记里高频出现的几种基本情绪。在保证类别可分的前提下，尽量贴近现实场景的表达方式，不把边界模糊样本强行塞进训练集。

## 标签定义

| label | 中文情绪 | emotion key | 趋势分值 (`score`) | 标注标准 |
| --- | --- | --- | --- | --- |
| `0` | 难过 | sad | -2 | 失落、伤心、孤独、低落、被忽视、被拒绝 |
| `1` | 焦虑 | anxious | -1 | 担心来不及、心慌、紧张、害怕考砸、对未发生的事过度担忧 |
| `2` | 生气 | angry | -2 | 愤怒、不耐烦、被冒犯、烦躁、抱怨、厌恶 |
| `3` | 平静 | calm |  0 | 平静叙事、日常陈述、中性提问、节奏平稳的状态 |
| `4` | 开心 | happy | +2 | 喜悦、成就感、放松、被支持、压力缓解、期待 |

> `sentiment` 数据库字段目前存储五分类 emotion key，不再存储 `positive / negative / neutral`。

## 数据来源

| source | 含义 |
| --- | --- |
| `multi_emotion_dialogue` | Hugging Face `zzhdbw/Simplified_Chinese_Multi-Emotion_Dialogue_Dataset`，字段 `text`、`label`，原始情绪标签按下表映射 |
| `manual_campus_anxious` | 大学生日记场景的“焦虑”人工样本（公共数据集没有焦虑类，必须手工补） |
| `diary` | Django 数据库里现存的五分类心情记录，按 `emotion_label` 或 emotion key 读取 |

### 公开数据集 → 五分类映射

| 原始标签 | 是否进入训练集 | 映射后 label / 中文 |
| --- | --- | --- |
| 开心 | 是 | `4` / 开心 |
| 伤心 | 是 | `0` / 难过 |
| 生气 | 是 | `2` / 生气 |
| 厌恶 | 是 | `2` / 生气 |
| 平静 | 是 | `3` / 平静 |
| 惊讶 | 否 | 删除（不属于五分类目标） |
| 关心 | 否 | 删除（信息量低，多为客观叙述） |
| 疑问 | 否 | 删除（非情绪类，多为问句） |
| 恐惧 / 担心 / 害怕 / 紧张 | 是（如出现） | `1` / 焦虑 |

### 焦虑样本补充

公开数据集里没有焦虑/恐惧/担心/紧张这几类，因此焦虑类完全靠手工写入。`ml/build_5class_dataset.py` 会通过两段方式生成约 260 条焦虑样本：

1. 一段精挑细选的大学生日记原句（约 100 条），覆盖期末/答辩/PPT/实验/项目/导师/DDL 等高频场景。
2. 一段“触发词 × 时间情境 × 焦虑感受”模板组合，按需补到目标数量。

## 不进入训练集的文本

| 类型 | 处理 |
| --- | --- |
| 强反讽（如旧库中的“奴才”那条） | 默认从 diary 来源里过滤，不进入训练集 |
| 信息量极低 / 单字符 / 表情串 | 不入训练集 |
| 高度相似的改写、重复 | `build_5class_dataset.py` 里按 `text` 去重 |

## 字段格式

`ml/data/processed/emotion_labeled.csv`：

```text
text,label,emotion,source,split,notes
```

`split` 字段会在 `ml/split_dataset.py` 后被填充为 `train` / `valid` / `test`，构建脚本本身只输出空字符串。

## 划分规范

`ml/split_dataset.py` 使用 `train_test_split(..., stratify=label)` 做两次分层切分，比例为训练 80% / 验证 10% / 测试 10%；标签分布图按五类动态绘制，颜色与图例不再写死成 2 类。
